# Готовые блоки: какой выбрать

Здесь лежат **готовые файлы** ConsentKit. Ничего собирать и устанавливать не нужно: выбираете подходящий файл, копируете его содержимое и вставляете в шапку (HEAD) своего сайта.

Все блоки работают одинаково: пока посетитель не нажал «Принять», счётчики и рекламные пиксели на сайте физически не запускаются. Блок не обращается ни к каким внешним серверам — всё нужное уже внутри него.

---

## Какой файл взять

| Файл | Для какого сайта | Размер |
|---|---|---|
| **`ru-bar.txt`** | Русскоязычный сайт. Баннер — полосой внизу страницы. **Начните с этого варианта, если сомневаетесь.** | 139,7 КБ |
| `ru-box.txt` | То же, но баннер — компактной карточкой в **левом** нижнем углу | 139,7 КБ |
| `ru-box-right.txt` | Карточка в **правом** нижнем углу — берите, если слева на сайте уже что-то есть | 139,7 КБ |
| `ru-modal.txt` | То же, но баннер — окном по центру экрана | 139,7 КБ |
| `eu-bar.txt` | Сайт на всю Европу: 34 языка, каждый посетитель видит свой | 187,2 КБ |
| `en-bar.txt` | Сайт только на английском. Баннер всегда английский, независимо от языка посетителя | 138,1 КБ |

Во всех блоках внизу баннера есть маленькая подпись «Сделано в E-COM Consult»
(в `en-bar.txt` и `eu-bar.txt` — «Made by E-COM Consult») со ссылкой на
ecomconsult.net. Не нужна — найдите в файле `"branding"` и удалите этот блок
целиком, либо соберите свой блок с флагом `--no-branding` (см.
[tools/README.md](../tools/README.md)); флаг убирает заодно и код брендинга,
поэтому блок становится примерно на 24 КБ легче. Лицензия MIT, вы ничего не
обязаны оставлять.

Первые четыре файла отличаются **только видом и положением баннера** — текст, языки и поведение у них одинаковые. Выбирайте на вкус, «полоса внизу» (`ru-bar.txt`) — самый привычный посетителям вариант.

**Почему карточка по умолчанию слева.** В правом нижнем углу на сайтах обычно уже что-то стоит: виджет чата, кнопка «наверх», значок мессенджера. Баннер слева никому не мешает. Если у вас наоборот занят левый угол — берите `ru-box-right.txt`.

**Про русские варианты.** В них три языка: русский, румынский и английский. Баннер сам смотрит на язык браузера посетителя: русскому покажет русский, румынскому — румынский, всем остальным — английский. Отдельно ничего настраивать не нужно.

**Про `eu-bar.txt`.** Он весит почти вдвое больше, потому что внутри тексты на 34 языках. Берите его, только если у вас действительно посетители со всей Европы. Для сайта на русском лишние килобайты будут грузиться на каждой странице впустую.

## Как поставить: 4 шага

1. **Откройте нужный файл** — например `ru-bar.txt`. Это обычный текстовый файл: двойной щелчок откроет его в «Блокноте» (на Mac — в «TextEdit»).
   *Смотрите файлы на GitHub?* Нажмите кнопку **Raw** над текстом — откроется чистый код, который можно выделить и скопировать.
2. **Выделите всё содержимое** — нажмите **Ctrl+A** (на Mac — **Cmd+A**). Выделится весь текст файла целиком, включая самую первую строку `<script>` и самую последнюю `</script>`.
3. **Скопируйте** — **Ctrl+C** (на Mac — **Cmd+C**).
4. **Вставьте в поле HEAD вашего конструктора — в САМОЕ НАЧАЛО**, выше всех остальных кодов (Яндекс Метрики, Google Analytics, любых других вставок). Нажмите **Ctrl+V** (на Mac — **Cmd+V**) и сохраните.

> **Где это поле в Тильде:** Настройки сайта → Ещё → **HTML-код для вставки внутрь HEAD**.
> В других конструкторах ищите поле с названием вроде «Код в head», «Custom HTML head» или «Пользовательский код».

После вставки **опубликуйте сайт** — в конструкторах изменения попадают на живой сайт только после публикации.

**Почему именно в начало.** Блок успевает перехватить чужие счётчики, только если стоит раньше них. Если вставить его после кода Метрики, Метрика запустится первой — и запрет уже не сработает.

### Как проверить, что получилось

Откройте свой сайт в **режиме инкогнито** (Ctrl+Shift+N в Chrome, Cmd+Shift+N на Mac) — иначе браузер вспомнит ваш прежний выбор и баннер не покажется. Внизу страницы должна появиться панель с кнопками «Принять всё», «Отклонить всё», «Настроить».

## Как поменять цвет кнопок

Цвет кнопок по умолчанию — синий `#2B50D8`. Его можно заменить на свой, не пересобирая блок.

**Правьте файл ДО вставки на сайт** (или, если уже вставили, — правьте файл и замените блок на сайте заново). Искать код прямо в поле конструктора не выйдет: там обычная форма ввода, и поиск браузера по ней не работает.

1. Откройте нужный файл в «Блокноте».
2. Нажмите **Ctrl+F** (на Mac — **Cmd+F**) — откроется поиск.
3. Введите в поиск **`"accent"`** — вместе с кавычками. Такая строка в файле ровно одна, промахнуться нельзя. (Не ищите по `#2B50D8`: этот код цвета встречается в файле шесть раз, и пять из них менять не нужно.)
4. Поиск приведёт вас к строке в самом конце файла. Выглядит она так:

   ```
         "accent": "#2B50D8",
   ```

5. Замените **только код цвета** — шесть символов между `#` и закрывающей кавычкой. Например, для вишнёвого цвета строка станет такой:

   ```
         "accent": "#C81E5A",
   ```

   Кавычки, двоеточие, решётку `#` и запятую в конце **оставьте на месте** — они нужны.

6. Сохраните файл (Ctrl+S / Cmd+S) и вставьте его содержимое на сайт по инструкции из четырёх шагов выше.

**Где взять код цвета.** Это тот же формат, в котором цвета задаются в вашем конструкторе: решётка и шесть символов, например `#C81E5A`. Подсмотрите его в настройках дизайна своего сайта — там цвета обычно показаны именно так.

> **Важно: у посетителей с тёмной темой цвет будет другим.**
> Эти блоки подстраиваются под настройки посетителя. Если у человека на компьютере или телефоне включена **тёмная тема**, баннер покажет свой собственный светло-синий цвет вместо вашего — так сделано специально, чтобы текст на кнопке оставался читаемым на тёмном фоне.
> Ваш цвет увидят посетители с обычной **светлой темой** — а это большинство.
> Поэтому проверять свой цвет нужно на компьютере со светлой темой: если у вас включена тёмная, вы увидите светло-синюю кнопку и решите, что правка не сработала.
> Нужен свой цвет вообще у всех, в любой теме — это уже пересборка блока, см. последний раздел.

## Чего делать не нужно

- **Не меняйте внутри блока ничего, кроме цвета.** Всё остальное — рабочий код. Одна лишняя запятая или удалённая скобка — и баннер перестанет появляться, а вместе с ним перестанет работать и запрет на счётчики. Внешне сайт будет выглядеть нормально, поэтому поломку легко не заметить.
- **Не вставляйте блок в текстовый блок страницы.** Только в поле для HTML-кода в HEAD: визуальные редакторы превращают код в обычный текст, и на сайте появится «простыня» из символов.
- **Не вставляйте два блока сразу.** Один блок на сайт.

### При обновлении ConsentKit блок надо заменить целиком

Блок — это **снимок кода** на момент сборки. Выход новой версии ConsentKit сам по себе на ваш сайт никак не влияет: исправления не доедут, пока вы не замените блок вручную.

Порядок такой: скачать новый файл отсюда → удалить из поля HEAD старый блок целиком → вставить новый.

**Ваша правка цвета при этом потеряется** — новый файл приходит с обычным синим. Поэтому, если меняли цвет, **запишите свой код цвета куда-нибудь** (или сохраните свой поправленный файл), чтобы не подбирать его заново.

## Нужна своя комбинация

Если ни один готовый файл не подходит — нужны другие языки, свой цвет сразу «зашитый» в блок (в том числе для тёмной темы), другая версия политики или список ваших cookie в окне «Настроить» — блок собирается под заказ одной командой.

Как это сделать, описано в **[tools/README.md](../tools/README.md)**.

> **Нужен Node.js.** Это программа для запуска команд, её ставят на компьютер отдельно. Если вы не программист — проще попросить любого знакомого разработчика: сборка занимает одну команду и меньше минуты.
