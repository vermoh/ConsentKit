A consent banner that holds trackers until the visitor answers

Most banners are decoration: the trackers fire on the first frame no matter which button the visitor presses.

ConsentKit holds dynamically inserted scripts (GTM, Metrica, Meta, TikTok, Hotjar) and tags marked type="text/plain" until consent. A plain <script src> written straight into the HTML has to be marked once — the dashboard shows which ones. 34 languages and Google Consent Mode v2.

How it works

  1. 1

    Paste one line

    A single line in <head> — on Tilda, WordPress, through Google Tag Manager or in plain HTML. No build step, no dependencies.

  2. 2

    Verify the domain

    First you prove you own the domain — with a meta tag or a DNS record. After that the install check shows whether the banner is live on the site and which tags are still unmarked.

  3. 3

    Scan and cookie table

    The scanner walks the site, finds trackers and cookies, and fills in the table your visitors see in the banner settings.

Features

Blocking before consent

Scripts added dynamically (the official GTM, Yandex Metrica, Meta, TikTok and Hotjar snippets) and tags marked type="text/plain" never send a request at all. A plain <script src> tag written straight into the HTML is prevented from executing and setting cookies, but its network request may already be in flight — those tags have to be marked up by hand. The dashboard shows you exactly which ones.

Cookie scanner

Walks your pages in a real browser, collects cookies and tracker requests, and sorts the findings into categories. You get a ready cookie table and a list of tags worth marking up.

Consent log

Every visitor decision is recorded: timestamp, policy version, chosen categories, method. CSV export on paid plans, for when a regulator asks.

34 languages

Every EU language and its neighbours: the banner picks the visitor’s browser language or the one you set. All strings can be overridden with your own.

Google Consent Mode v2

ad_storage, analytics_storage, ad_user_data and ad_personalization are set before tags load and updated on choice. Events also go to the dataLayer for GTM triggers.

WordPress, GTM, Tilda

A WordPress plugin, a ready Google Tag Manager container, and a self-contained <script> block for site builders that will not let you upload files — free Tilda, for instance.

Who it is for

Tilda sites

Nowhere to upload files — take the self-contained block and paste it into “HTML code for HEAD”. One paste, no plugins.

WordPress and WooCommerce

The plugin installs by copying a folder, settings live in the admin. It works with caching plugins too: the banner does not depend on PHP.

Online shops

Ads and remarketing run on Consent Mode v2: your tags get correct signals instead of being switched off wholesale.

Agencies
